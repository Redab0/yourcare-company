# Provider input and transport inventory

Every serialized body/query leaf sent through the production `ApiClient` is checked by `RequestSecurityInterceptor`, before secure storage is read. Socket messages use the same walker independently. Common bounds are client resource safeguards: depth 16, 1000 entries per collection, 10,000 nodes, 16KiB per string, 1MiB aggregate text. They are not claimed to be backend DTO limits. Known numeric/boolean/text/identifier fields also enforce types; nullable fields remain nullable. Human text is conservatively trimmed; punctuation/Arabic/HTML-looking plain text remain intact. Passwords and opaque credentials stay byte-exact and retain JSON-escaped characters.

The following lists all direct text widgets and shared `_TextField` call sites found in `lib` (including DEV preview). Shared laundry numeric/price wrappers and the upholstery wrapper are represented at their implementations and visible call sites. Non-text selectors (role/service/day/hour/status/category/options/team/permissions), upload pickers and server-returned IDs flow through the same typed serializer/guard. Existing UI-only profile editing is called out explicitly.

## Transport coverage

| Surface | Enforcement |
| --- | --- |
| Auth, user/company profiles, covered/custom services, staff/permissions/teams | Exact configured HTTPS API origin and `/api` scope; raw-path traversal/injection rejection; serialized type/size/content checks; endpoint-scoped staff and contact rules; no authenticated redirects. |
| Housekeeping, upholstery, car wash, auto bid, shared availability | Shared transport guard plus raw numeric draft checks before submitting; separate KWD and percentage validation; zero-price car-wash choices kept; service/identifier/weekday/hour checks. |
| Offers, jobs, extra invoices, laundry catalog/prices/settings/invoices/status | Shared guard; specific laundry quantity/price/minimum-charge/size/service/invoice-list/status rules; positive extra fees; existing server-authoritative status/payment semantics preserved. |
| Documents, statistics, calendar, request searches/pagination | Shared query guard including bounded search, finite numbers/date parse/range; documents capped while streaming at 10MiB before buffering. |
| Generic `/upload/multiple` | Local client count/size/aggregate safeguards (deployed backend enforcement unverified), safe filenames, file-header image signature detection and actual MIME at repository; multipart metadata guard does not consume arbitrary streams twice. |
| Socket.IO chat | Exact configured HTTPS chat URL; atomic bounded token/user snapshot; lifecycle generation blocks logout races; fresh socket manager; outgoing field validation before connection/emit; acknowledgement/connection timeouts; native HTTP upgrade redirects disabled. |
| Remote config store link, contacts, maps, media viewer | Store links restricted to HTTPS Apple/Google store hosts; phone link digits/length; maps already validate finite coordinate ranges; media viewer requires safe HTTPS URL. No bearer credentials sent to media/store/contact destinations. |
| Standalone HTTP | None found: provider has one shared Dio instance; `http_parser` is MIME metadata only. |
| Analytics/Crashlytics/diagnostics | App-authored logging removed; diagnostics records/sinks disabled; Analytics and Crashlytics dependencies/plugins/native upload hooks removed. Firebase push and Remote Config retained. |
