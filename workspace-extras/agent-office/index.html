BEHIND THE LITTLE WORLD

Real work. Robot coworkers.

The office reads your local Codex activity every two seconds. Each robot represents a task agent or a child agent.

  • Workstations: commands, file edits, and thinking.
  • Research lab: reading files and web research.
  • Meeting room: agents with a recorded message exchange within the last 45 seconds. This is a visual window around a message, not the duration of a call.
  • Lounge: completed or interrupted tasks.
  • Waiting area: agents needing input, or whose status is uncertain.

“Recent” shows the last 24 hours plus every active agent. The crew list includes every agent in the selected view; use the floor controls to browse large teams. Archived tasks and internal approval reviewers are excluded.

This is a read-only local view of Codex’s activity records. Private reasoning, command output, and message bodies are never displayed. Cloud-only activity is not available through this local connection.

The preview is clearly labeled and uses fictional agents.
